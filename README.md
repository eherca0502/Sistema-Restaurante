#  Sistema de Gestión para Restaurantes

Sistema web desarrollado en PHP y MySQL para la administración de restaurantes

## Características

* 🥡 Punto de venta (llevar y domicilio)
* 🍽️ Gestión de comandas por mesa
* 👨‍🍳 Panel de cocina
* 📦 Control de inventario
* 🏷️ Promociones
* 💰 Corte de caja diario
* 🧾 Generación y reimpresión de tickets
* 👥 Administración de usuarios
* 📱 Control de asistencia mediante códigos QR
* 📊 Historial de ventas
* ⚙️ Configuración del restaurante

## Tecnologías

* PHP
* MySQL
* Bootstrap
* JavaScript
* FPDF

## Instalación

1. Clonar el repositorio.
2. Importar la base de datos MySQL.
3. Configurar `config/database.php`.
4. Ejecutar el proyecto en XAMPP o servidor compatible con PHP.
